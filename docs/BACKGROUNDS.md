# 背景素材

確認日: 2026-10-17

内蔵のドット・ストライプ・チェックは、このアプリ用にCanvasで描画する独自の幾何学模様です。外部の画像素材やフォントを配布・取得していません。端末から選ぶ背景画像は、写真と同様にブラウザ内だけで処理・保存します。

ユーザーが言及した素材サイトは **OKUMONO** として調査しました。

- [OKUMONO 利用規約](https://sozaino.site/kiyaku): 作品の背景・飾りとしての使用は広く認めていますが、加工の有無にかかわらず素材としての再配布や、背景・デザインテンプレート等として不特定多数に配布することは禁止されています。
- [OKUMONO よくあるご質問](https://sozaino.site/qa): デザインテンプレートの配布・販売、加工可能な背景等としての不特定多数への配布にも制限があります。

完成作品の背景に使うことと、編集アプリの選択可能な素材として組み込んで配布することは用途が異なります。この公開アプリへの同梱は再配布に当たり得るため、許諾なしの内蔵は採用しません。OKUMONOの画像はダウンロード・同梱していません。問い合わせや許諾取得も実施していません。

手元の素材を背景画像として選ぶ際は、その素材の利用条件に従って完成画像を使用してください。
